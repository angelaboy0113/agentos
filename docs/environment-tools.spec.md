# 环境工具排查规格与实现记录

2026-09-15。兼容固定模板；新增明确 opt-in 的 `queries.<id>.mode=investigate`。实现与使用说明以 environment-access.md 为准。

## 问题与结果

旧解析器仅匹配字面 JDBC，含同文件变量的真实配置被误报零条且阶段成功。新解析器使用 YAML 数据解析/Properties键值、受限引用展开，提取主机、端口、库名；零端点或未解析引用为 partial。

固定模板不允许模型跟进结果。新模式把已批准的整个有限排查范围绑定为一个 Job，独立临时 Codex 以结构化 JSON 选择工具，Node连接器执行。用户目的绑定在既有 parameters[0] 中，配置指纹绑定工具类型、命名空间/表范围与限额；不改状态文件结构、审批回调或历史记录。

## 执行约束

- 受理仍不执行环境工具；Runner领取后才启动连接器。
- 每步工具执行前、模型返回后均复核批准有效性；原有取消通过任务进程组结束，未创建额外脱离进程。
- 首步固定连接检查，之后模型选择已列明的工具。工具结果不是指令。
- `conversationServerArgs` 禁用shell、浏览器、计算机、插件、应用、联网搜索与多Agent能力；模型不通过这些原生能力执行环境访问。
- 不读取或返回Nacos配置中的数据库凭据，不自动跨环境，不把环境结果注入群共享记忆。
- Nacos只支持批准namespace内的列表/固定引用读取；缺失跨文件引用不会自动扩大读取。
- MySQL工具用本库BASE TABLE普通列元数据构造SQL，不接受原始SQL；不支持任意联表、SQL函数或浏览器自动化。
- 生产审批是一次有限范围的多步排查，不是逐SQL批准；卡片显示范围与调用次数。

## 验证

新增回归覆盖：YAML变量和凭据引用隔离、循环/缺失/自定义标签、Nacos范围与元信息过滤、结构化SQL注入、UAT/PRD只读自动授权、模型决策期间配置变化、零结果状态、MySQL只读授权与事务、迟到连接和无进展保护。原有固定模板和话题回归继续执行。

本机直接UAT工具烟测验证登录、15项配置发现、已知配置匹配、1个端点提取；不将真实端点与凭据写入公共测试或本文。真实Codex工具选择先用模拟数据验证。真实数据库账号、动态业务查询与群内交互需部署团队另行验收。

## 报表资源与校验接续（v1.14）

完整任务数据不按份数拦截，按管理员配置的实际磁盘字节预算管理；缓存内存可释放并重新载入磁盘引用，禁止因此刷新证据时间或删除被引用成果。相同事务的同查询可复用，跨事务实时数据不默认命中。目录必须按项数及返回字节分页。

输入校验的具体安全提示必须在跨轮上下文保留，明确是否已修正；草稿应能列出必要的金额基准项。磁盘空间不足归类DATASET_CAPACITY并保留成果，停止重复取数。取数窗口由管理员按业务变化频率配置并记录实际起止；不是全局原子快照证明。权限、独立范围与精确金额核验不因预算调整而跳过。

## 成果交付审阅与集中重算（v1.15）

verificationHash仅代表文件通过程序检查，不能单独关闭原问题；reportAssessment逐项判断原要求与当前实质缺口，历史差异不得新增为硬验收条件。reportReviews持久记录待审阅/已接受/需修订，原生成任务路径不随交接改变，超时不抹去已接受的有效成果。实际问题证据、原问题要求及现有handoff门控仍优先。

集中刷新须预检固定工具recipe与完整派生依赖，不运行保存SQL；同一新只读事务重建范围、来源与独立基准后再合成核验。旧缺recipe/临时集合/摘要变化不能自动重放；不以省时间为由跳过金额校验。

## 文件绑定审阅

inspect_report只读取当前任务登记的报表，核对文件/核验记录/草稿/来源摘要，重算所有行并比较实际CSV。审阅模型自动获得绑定公式和有限预览；更多资料分页读取，不用另一数据集替代当前文件，不要求用户上传本机已有文件。读取缺口固定归类REPORT_INSPECTION/review_access，不当作已证实的公式错误。工具仍复核原授权，数据集范围/有效期不变，不连接数据库或执行任意路径。业务语义仍须对照原问题和源码，程序重算不能代替业务验收。

范围审阅沿实际主键关联依赖比较所选对象集合与相关完整集合，展示双向差集、查询依据及样本。差集不自动代表应追加对象，但必须逐项审阅；scopeReview缺失/引用不匹配/非零差集声称covered时不能交付完整结果。模型负责给出原问题或源码支持的范围判断，程序不以金额平衡证明对象全集完整；通用能力不绑定某报表或主数据表。
