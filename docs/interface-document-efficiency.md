# 大范围接口文档的执行与交付

架构、接口全集和生产版本取证遵循相同权限与证据要求，不以缩减接口、跳过未核实项、固定任务时长或轮次截止来提速。

## 当前运行版本

TSF `current_inventory {}` 批量读取本入口已登记的全部应用、部署组、当前配置镜像和完整 Pod 分页。沿用独立读并发4；每个请求仍执行授权校验，组命名空间在读取前后检查，缺组明确 `complete=false`，缺页报错。只返回已审核投影，不返回环境变量、YAML、凭据或执行部署。各请求时点不同，不声称事务快照。错误不返回虚假全集，原子工具失败后可定向用原有工具排查。

调查当前架构优先使用此工具；当用户要求上线时间、部署变更历史或某个具体版本证据仍缺失时，继续在实际所需应用和期间查询 `deployment_history`。新工具不是取消历史能力，不用实例创建时间冒充上线时间。运行器持久化完整结果并将其交接给源码阶段，接续可以读已保存证据，不重复获取同一批元数据。

## 固定祖先与另一个生产提交

`sourceHistoryQuery` 的 `targets` 为 `null` 或 `[{repository,commit}]`。旧结果没有此字段仍兼容；只在reason中出现其它SHA的旧请求会先要求结构化说明，不先启动下载。新 schema 明确输出它。该工具只补齐当前问题固定提交的祖先。发现目标不同于原固定提交时返回 `SOURCE_HISTORY_TARGET_MISMATCH`，不启动无意义的全量祖先下载，原 HEAD、证据和任务身份保持；同会话继续核查其它可用证据，所需生产源码版本缺口仍如实保留。

这没有新增任意分支/提交读取授权，也没有实现任意生产版本下载。模型应先检查缓存已有对象；如果独立分支不在当前源码范围或对象仍缺失，应报告准确目标与来源，不把另一个 SHA 只写进自由文本 `reason` 后请求祖先工具。正常祖先历史调查、已有完整历史复用、跨进程锁和 Git 元数据边界规则不变。

## 集中生成接口目录

任务产物通知提供 `scripts/render-interface-document.mjs WORKING INPUT.json OUTPUT.html`。仅接受本工作目录内独立普通文件，拒绝越界/链接/覆盖输入；内核原有写边界仍有效。输入包含 title、scope、sections、endpoints、models；接口字段包括 id/service/method/path/category/description/plain/status/request/response/source/modelIds。文本必须由已核实源码和原需求产生，缺失事实保留未知，不能把字段名自动推断成业务规则。

渲染器对完整输入一次构建静态 HTML，集中模型只列一次，所有接口留在目录与详情，模型引用必须存在，重复 ID 报错，不静默去重。HTML 转义内容，不运行脚本/外链；最终仍通过原 `documentRequests` 实际渲染、哈希绑定和审阅流程。它不自动扫描业务仓、不验证业务结论，也不声称旧稿和新稿语义天然相等。

建议先保存可重用结构化目录、增量合并证据，相关证据齐备或真实缺口明确后集中生成最终文件；用户需要草稿时仍可以输出。不是禁止阶段交付或新增任务限制。

## 大 HTML 的投递

单 HTML 超过现有29,000,000字节传输分卷阈值时，先用流式 DEFLATE 生成普通 ZIP，内含原 HTML 及 SHA256 说明；压缩包小于同一阈值则一份附件交付。原文件及哈希不变，临时 ZIP 在投递流程结束清理；不将 ZIP 的哈希说成原 HTML 哈希。压缩后仍过大时继续现有无损分卷。CSV/Office 等其它格式保持原行为，不扩大平台实际上限、不声称任意大文件均可单附件发送。

## 验证

专项覆盖：几千接口完整保留、模型集中定义、未知/恶意文本转义、重复键/悬空引用、真实 ZIP 解压逐字一致；TSF 全页/命名空间变更/越界与授权；不同目标 SHA 不下载无关历史。原范围历史、文件核验、业务金额和多系统路由回归必须继续通过。

隔离回放只能证明结构化目录构建/传输能力，不等同新真人题或整题提速。性能验收须用同一提问、相同要求发起新真人任务，记录版本、源码提交差异、数据/缓存边界、最终文件及耗时；成败均撤回本人测试话题，不改原用户卡片。新增外部证据缺口不强绿。

无新增私有配置或权限。发行包带生成器、模块、测试和设计技能。正常空闲发布；回退保留当前任务、文件与凭据，使用专用分支已审阅撤销正常部署，不倒灌旧状态。其他操作系统与完整跨机迁移须单独验证。
