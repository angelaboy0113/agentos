# 任务卡凭据回复修复验证

版本：v1.3.2  
日期：2026-09-21

## 故障与修复

用户在等待网页登录的飞书任务卡中回复 `@机器人 账号 / 密码` 时，凭据处理早于普通会话的 mention 清理，导致机器人显示名被拼进账号。固定登录程序仍会提交表单，登录页因账号错误继续停留，旧回复又把所有未登录结果统一描述成验证码、短信、扫码或未知结果。

凭据入口现在使用飞书事件携带的 mention key 和名称先清理被回复的机器人，再解析自然格式。网页快照同时区分可见的账号密码表单与已进入的同源验证页面：前者提示核对账号或密码，后者才提示在本机完成验证码、短信或扫码。凭据内容仍不进入任务状态、模型上下文、日志或测试数据。

## 验证

回归使用合成账号密码和本地临时页面，覆盖显示名称 mention、mention key、任务卡归属、负责人校验、凭据不回显、登录表单仍可见及验证页分类。发布后还应确认服务健康、飞书消费者在线，并由真实任务的下一次登录结果验证业务账号；自动化回归不证明真实账号有效。
