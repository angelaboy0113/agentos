# 接口调查与环境执行效率（1.120.0）

用户询问少量字段对应的接口时，先核实字段含义、源码映射及关联键，沿已确认环境选择定向元数据；不先漫游管理平台接入说明。已确认的口径可复用，时效性数据仍重新取证。不能把申请人工号当业务负责人工号、历史订单上的人员当固定国家负责人；字段映射真实缺口要明确说明，不用相似字段冒充。

环境规划器使用持久模型会话，`environmentPlannerInstructions(kind)`只加载共同约束及当前域的操作说明。website不再携带期间报表/多表金额整理工具长说明，数据库不再携带网页图标/iframe说明；所有域保留证据、不扩权、不盲重放、原任务完成标准。模型和推理强度不变，源码分析与最终交付沿原执行器。

`batch_read`可合并目录中已提供的独立观察；`execute_read_plan`可通过真实前一步结果的`$result`引用下一步读取参数，工具继续逐步核对原任务授权。新增支持`browser_snapshot`、`browser_read`、`browser_diagnostics`、`browser_assets`、`browser_inspect`、`browser_frames`；不含点击、导航、输入、登录、提交、切换页面/iframe。快照会生成新控件引用，动作前核对最新引用；并行批次不以某个旧快照引用驱动动作。页面正文续读必须使用同一内容摘要和连续偏移，内容变化仍拒绝拼接。保存数据集、报告及独立金额核验原流程保持。

导航点击后，若当前为导航或已观测到读取请求，复用截图既有的加载探测，等待当前页面/请求稳定再返回快照，并给出`observationReadiness`。加载探测超时是页面观察状态，不自动重试动作、不终止整项任务，也不冒充业务失败；模型继续按当前诊断读取。无需为读取尚未返回的页面反复模型往返。不会关闭重开浏览器或修改登录身份。

文档读取型POST按[RestCloud只读适配](restcloud-readonly.md)登记固定非敏感请求体；前端调用和真实页面必须单独核验，不因为接口名像读取就开放。此项配置改变需原任务票据按既有指纹规则复核，不把程序修复等同业务三字段已齐。

验证应分开记录：批量/依赖计划和权限边界回归、真实浏览器加载及固定请求体读取、上下文长度变化、真实同题新卡答案及总耗时。对照相同模型/身份/环境、原题和已有澄清、源码/缓存情况；剔除人工等待与端到端总时长分别标明。不能用提示词缩短比例声称整题等比例提速。其它OS和完整跨机迁移未经实测须注明；新增模块、测试和本文纳入迁移代码包。
