# 原生表格分页输入与跨阶段接续

1.71.0。此功能把当前任务已授权、原机器人读取的电子表格分页保存为任务输入，供后续同系统同环境数据库核对；不是任意文件、路径或跨系统数据导入。

`connection`返回真实网格。`read_cloud_sheet`可按行或列分页，控制面保存不可变分页原文及SHA，并按任务、原机器人、项目、分级、文档、sheet、网格和revision分别登记。缺页只返回缺口，不能当完整输入；不同revision不合并。同版本完整覆盖后核对重叠单元格、类型及完整范围，再自动生成`inputAttachment`。重复页幂等；分批原始`readAt`逐一保留，不声称同一事务快照。版本缺失不能拼接多次读取；须一次取得完整范围或取得可信版本。空值、前导零、重复记录不去重、不补业务零，行号仍为原表行号。

旧任务已有完整保存的分页时，在原文档授权范围使用`restore_cloud_sheet_input({resultRefs:["tool-result-…"]})`：只读取本任务当前环境、摘要有效且类型为`read_cloud_sheet`的保存结果，不发新平台请求；不接收路径、JSON、其它文档URL或其它任务/系统/环境引用。每页仍走相同覆盖/版本/重叠校验。已有完整输入直接复用其attachmentId，不反复读取原文档。

数据库阶段从`inputAttachments`选择实际ID，调用`import_task_input`，按明确0-based列索引和类型导入，再建立完整编号集合或关联数据。输入不是SQL查询结果，也不能作为独立金额核验基准。草稿、独立核验、实际文件内容及上传投递按原流程分别验收。

分页登记/合并与最终输入都检查原任务租约、身份和文档范围；文件拒绝符号链接和越界，组装前后核对当前分页清单，不因并发读取注册过时完整结果。页文件路径留在任务元数据，随当前历史保留机制保护和清理。迁移须保留整个runtime/data及分页清单；旧程序可继续读取已形成的完整输入，但不认识新分页恢复工具，回退前核实未完成的分页任务。代码包包含新模块与回归，无新依赖、飞书权限、私有配置或整任务截止。

部署仍须自然空闲并备份，只重启本实例。离线/保存数据回放不代表真实数据库核对或文件交付成功；跨Mac与其它操作系统须单独验收。
