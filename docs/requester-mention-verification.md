# 发起人终态 @ 提醒验证

日期：2026-09-14
版本：v1.0.1

## 已验证

- 普通群聊：结果卡完成后，以原机器人 profile 回复原消息，使用飞书文本消息原生 `<at user_id="ou_xxx"></at>` 语法提醒本次提问人。
- 跨 Agent 任务：执行卡仍由当前角色机器人展示；最终提醒固定由原任务 profile 回复最初消息，因此不把一个应用的 `open_id` 错用于另一个应用。
- 任务中间的待审批、待补充和只读分析自动交接不会发送“任务结束”提醒；最终 completed / blocked / failed / cancelled 才发送。
- 卡片成功而提醒失败时，只重试提醒；稳定幂等键防止不确定网络结果造成重复通知，Codex 和 Job 均不重跑。
- 非群聊不追加多余 `@`；非法或可注入的用户 ID 失败关闭。
- Node.js 22 全量回归 77 项通过。

## 仍需真实群验收

自动测试验证了消息内容、profile 路由、幂等与持久化，不冒充飞书客户端真实通知验收。服务重启后，在目标群分别用两个真人向任一 Agent 提问；每条回答结束应收到对应发起人的 `@`。再创建一条可结束的任务，确认只有最终结束时提醒原发起人。
