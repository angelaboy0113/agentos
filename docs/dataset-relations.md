# 已保存数据的关联与配置展开

适用版本：1.62.0。更新日期：2026-11-05。使用当前 Node 22.x，无新增依赖。

`relate_dataset` 用于已经完整取得的数据之间的关联，例如客户与多渠道配置、仓库与商品范围、项目与成员。无需为拆分字符串申请通用 SQL 权限，也不重复查询已取得的数据。工具目录和环境规划器共用实现，适用于 MySQL、MongoDB 已保存数据；仍按原任务、系统和环境指纹校验每个引用。

## 入口与参数

先用 `list_datasets` / `inspect_dataset` 核对实际字段、完整性和取数时间，再声明主来源的 `keyColumns`。键为文本，保留前导零；复合键用数组，缺失或重复的真实行键报错。工具不接受代码、正则、SQL 或文件路径。

```json
{
  "datasetRef": "<本任务完整客户来源>",
  "keyColumns": ["customer_id"],
  "scopeEvidence": "<源码确认的关联与空配置规则>",
  "joins": [{
    "datasetRef": "<本任务完整商品来源>",
    "leftKeys": ["configured_ids"],
    "rightKeys": ["id"],
    "rightRowKey": ["id"],
    "relationship": "lookup",
    "fields": [{"column": "code", "as": "product_code"}],
    "split": {"delimiters": [",", "，"], "whitespace": true, "trim": true, "duplicates": "set"},
    "empty": "keep",
    "unmatched": "drop"
  }]
}
```

这是合成示例，不代表所有业务都应排除未匹配记录。`empty` 与 `unmatched` 必须分别指定 `keep/drop/error` 并说明依据；保留时右侧为 null，不能补零或猜作全部商品。没有 `split` 时是复合等值连接。拆分只用于已证实的文本列表，分隔符按字面匹配，不能猜测编码中连字符的含义。

`lookup` 要求右匹配键唯一，重复报错；`expand` 保留一个匹配键的全部真实行，`rightRowKey` 声明各行实际粒度。多个 joins 按依赖顺序一次执行。合法的一对多组合可能产生显示值相同的行，不能仅按输出列去重。`set` 是成员集合匹配，重复 token 不重复输出，并按右来源顺序；`preserve` 保留 token 次数。

可选 `project` 仅保留需要的实际字段并改名，支持已核实文本枚举的 `labels` 和 `unmapped=keep/error`；null 保持 null，数值金额列不能改成标签。稳定 `relation_key` 来自真实行身份和显式重复次数，不是业务编号，`compose_report` 应使用这个键。可选 `rowOrder=source` 保留来源顺序；默认仍按键排序，刷新沿用保存的选择。

## 文件核验与交付

工具只生成派生数据集，不代表 CSV 已生成或送达。继续 compose、finalize、实际文件检查与报表审阅。完整范围须追溯完整原始主来源；关联配方从所有依赖重算，核对行键覆盖、空值和排除审计。它证明组装可重现，不能冒充独立原始金额证据；数值分量仍需不同原始查询核验，不取消现有权限或完成门控。

大 CSV 沿原有飞书分卷交付：每卷重复表头，不截断行；文件生成、实际核验、上传、各卷回执和完成通知分别检查。页面列表与数据库范围不一致时，核对过滤、组织及账号范围；没有逐户证据不能猜成权限错误，也不能把数据库重建冒称同账号页面原生导出。

## 恢复、刷新与维护

派生类型 `dataset_relation/version=1` 保存参数、字段来源和每步匹配/空配置/未匹配/重复 token 数量，继承真实取数起止时间。恢复与定稿重新计算，篡改或依赖缺失拒绝交付。`refresh_report` 先验证整个依赖图，再在当前授权内每个原始来源读取一次，重建关联及草稿；不执行保存的原始 SQL，不把旧数据当实时快照。参数错误保存在原任务工具结果，原错误分类不被诊断存储失败覆盖。

无新增部署配置、权限或任务时长/轮次/调用次数限制。按实例维护流程等待任务、消息和投递自然空闲后升级和重启唯一服务，不强停用户任务。迁移保留完整 `data/exports/<JOB>/datasets`、所有行分块、来源、配方、CSV、核验及投递状态；不能只复制最终文件。旧版不能重算本配方，回退前停止新功能使用并保留证据，处理未完成任务和待投递后再按维护流程回退，不回灌旧状态。

合成回归覆盖多系统/环境并发、空值、复合粒度、一对多、重复 token、恢复、篡改、集中刷新和实际 CSV。当前 Mac 实例另有获准历史全量数据的回放记录；完整私有跨机迁移及其它操作系统未实测。测试通过不等于任何新报表已实际交付。
