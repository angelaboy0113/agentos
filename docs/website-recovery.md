# 空白、加载与原页面恢复

同一 question/profile/项目/环境/origin 的续查共享一个页面绑定。阶段结束只释放 job 占用，不关闭用户标签；下一阶段优先沿用原 tab。只有用户已关闭该 tab 时才取得一个替代页，`about:blank` 则在原 tab 内恢复原批准目标，避免小步骤间反复新建/重新定位。

`connection/browser_open/browser_snapshot` 遇到本任务页为about:blank时，按原批准的websiteTarget（含原查询参数）重新打开；任务自己的标签页被关闭或崩溃时重新获取页面。保持机器人/项目/环境、登录会话与网络范围，旧控件引用失效，不将别人的标签/角色作为回退。模型不能传任意URL、脚本、强制绕权或凭据。

普通网站工具目录提供 `browser_recover({})`：安静空白外壳可按同一目标重载；有读取正在进行则返回进度，不反复导航；静态依赖受阻/下载失败先返回具体证据，沿已审核资源或部署脚本继续排查。它不自动扩大CDN/业务API授权、不绕过验证码、不重复提交登录，也不是无限刷新循环。单个请求原超时与真实授权仍保持，没有整任务耗时/轮次/调用上限。

网页交互后仅真实认证状态返回loginRequired；内容暂空或请求未完成返回loading，不能误报“登录已过期”。页面按钮/表单可见不证明可编辑、已经提交或业务成功；必须结合角色/服务校验与当前业务状态核实。旧取证时点、旧OA实例或旧数据库revision不能当当前状态，多轮补查需明确版本/时间差异。

部署JS目录同时包括该页实际请求过的异步脚本，支持Webpack等会在加载后移除script标签的页面；不是猜chunk哈希或遍历任意目录。JS请求返回SPA/登录HTML会报BROWSER_ASSET_RESPONSE，引导读取最新目录，不能把HTTP200当有效脚本。读取结果/摘要与固定源码分开，前端分支只说明界面规则，不能凭它保证后台/OA写入同步。

隔离Playwright已验证blank自动恢复、安静空白、关闭页、引用失效、异步脚本、HTML伪JS及加载不误报登录。macOS共享Chrome只提供原目标about:blank/关闭页恢复；不声称有完整隔离网络监控、安静空白自动判断或真实Apple事件端到端验收。其它OS和整套私有迁移未验证。无新依赖、私有配置或权限；代码包须包含本文和回归。

正常跳转销毁DOM上下文时，只重试一次该幂等页面读取，等待DOMContentLoaded后重新检查原授权；不重放点击、登录提交、模型会话或业务查询。真实认证/权限错误保持原分类，不被导航恢复吞掉。

已审核精确GET的is/has/can开头布尔状态查询可读取启用状态元数据，不能把isEnable之类的配置检查误判为“启用”写操作；未审核路径、POST或删除/执行等动作仍拒绝。仅维护者核对实际用途后登记，模型不能自行加白。

公共组件文件名包含create/clone等动作单词时仍不默认越过业务写门控；维护者核对后为实际脚本建立精确GET静态绑定。原应用HTTP仅允许同源绑定，跨域仍要求HTTPS；不允许fetch/document/POST将静态绑定当API授权。

普通应用入口登录完成后沿用站点已加载首页，不无条件重开入口导致第二次跳转/空白。只有任务明确绑定websiteTarget业务页面且当前页不同，才恢复原目标；已有筛选参数保留。
同源可见内嵌页通过browser_frames/browser_frame选择正文；隐藏/跨域/移除/跳转帧拒绝，切换后旧控件引用失效。隔离浏览器截图对所有帧遮挡敏感输入。

查询/搜索/重置按钮的汉字间排版空格按同一只读动作识别；不会把提交/撤回等业务写按钮纳入。

登录页不会阻塞已授权入口的公开部署脚本取证：先检查browser_assets目录，模型仅能读取公开脚本及已保存证据。真实业务页面仍需认证，wait_for_website_login保留原问题等待已有凭据恢复。公开脚本读完交回源码审阅，authenticationVerified=false/publicAssetsOnly=true，不算登录成功，不证明物理表、业务数据或后端校验。无公开资源或确需私有内容时仍走原登录等待。


## 同应用路由纠正与参数核验

网页工具 `browser_navigate({url})` 在当前任务的原应用、环境、授权和凭据会话内跳转到已从页面菜单或固定源码确认的只读地址。不要推断站点一定使用 `#/`：先核对 snapshot 的 `route.mode`，以及真实菜单打开的地址。`url` 隐藏查询值，参数是否存在应读 `route.queryKeys` / `route.hashQueryKeys`；这些字段仅含非敏感参数名称，不含值。脱敏地址不能作为参数丢失证据。

工具对地址重新执行相同的应用路径、来源和只读校验，拒绝凭据、异源、其它应用及修改动作；每次仍核对任务授权。不会点击保存、重放接口或扩大读取范围。导航后必须重新读取控件；原引用失效，内嵌页选择清空。独立浏览器在 blank/登录恢复时保留最新只读目标；日常 Chrome 首次及跨阶段绑定显式深层目标，普通快照不会重置正在浏览的页面。未完成业务核验时仍如实部分完成，不将导航成功等同业务结论已证实。

回归入口：`node scripts/test.js test/website-route-continuation.test.js test/shared-chrome.test.js test/website-recovery.test.js`。不需要新增配置或权限；原只读接口边界保持。迁移代码包含新增回归和本文，私有迁移仍保留原网站环境配置、凭据库和任务证据。其它操作系统、真实日常 Chrome Apple Events 与全量跨机路径需单独验收。


## 本机请求门控与账号错误分别处理

`browser_diagnostics.blockedRequests` 现在保留方法、脱敏地址和本机拒绝分类。`READ_ENDPOINT_REVIEW_REQUIRED` 表示尚未登记的精确 POST 请求（如名词式筛选信息、尾部版本号的列表接口），不代表账号失效、业务权限不足或空数据；`REVIEWED_METHOD_MISMATCH` 表示与审核方法不同，`REQUEST_ORIGIN_SCOPE` 表示不同来源，`TASK_AUTHORIZATION_REQUIRED` 表示当前任务授权复核未通过。不得为这些状态要求用户重复发送密码、改请求方法绕过或把空列表补零。

维护者先读取实际前后端实现及部署入口，确认接口只有查询用途，再在该项目、环境、网站条目、查询模板的 `readEndpoints` 增加精确方法与路径；不会因一个系统审核而向其他系统开放。先核对页面初始化依赖，再核对目标列表的全部分页、实际筛选与组织范围，保留之前有效数据和固定源码。代码不包含业务接口白名单，实例配置变更按安全部署流程生效。审核配置示例：

```json
{"method":"POST","path":"/api/referenceOptions","reviewed":true}
```

该配置不放开保存/提交等写接口，也不会自动证明任何接口只读。字段、日志、认证头及请求正文不进入诊断。通过合成真实浏览器测试覆盖未审核前置请求阻塞、审核后同标签完整加载、并行不同系统/环境隔离及业务写入拒绝。

### 数量问答与文件交付
仅问多少家或去重数量时，可在原卡直接交付经完整来源与独立关联核验的数字，不把模型自行提出的CSV升级为强制验收条件。完整清单、金额/分组报表及显式导出仍走原文件核验。旧任务按当前用户原问题重新判别；不改取数范围、金额核验或权限。网页集合转为通用可重放数据集仍须有真实来源登记，本修复不宣称已新增任意JSON导入能力。

### 短分页与跨阶段范围
只读browser_read/browser_snapshot不论展示长短均保存到本任务带环境作用域、授权检查及摘要的工具结果库，短末页仍直接显示并附resultRef。跨阶段复用不重开网页，仍复核当前授权；无任意文件路径导入或跨任务共享。调查purpose目录反映实际无旧200字上限的执行语义，包含必要真实范围或数据集引用，不能只引用未传递的nextStep。模板查询的普通参数约束保持。
