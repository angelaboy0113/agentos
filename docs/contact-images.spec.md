# 联系人信息图规格

目标：在原飞书提问话题中，以机器人当前通讯录权限查询姓名/工号，确认唯一人员后回复本机后台生成的信息图。

验收：AI类型化意图；工号字符串精确匹配；完整分页后确认候选；重名不自动选择；候选绑定提问者/问题/群/项目/profile；发送前复核权限、可见字段与文件摘要；幂等重试仅投递；不使用user身份、不执行桌面动作、不把个人资料加入团队知识。

失败处理：没有字段权限说明缺字段；数据范围未找到不能断言人员不存在；分页异常不宣称完整；生成失败不伪造图片；权限/配置/字段变化时拒发旧图片。管理员批准权限属于真实外部条件，不用模拟结果代替。

不在本次范围：任意流程图输出、原生名片消息、飞书客户端真实截图、真实头像下载、多机人员索引与部分用户组范围解析（全员根部门可核实时已支持完整遍历）。实现入口为contact-directory.js、contact-image.js、conversation.schema.json与原消息出站客户端。

部门人数：类型department与姓名/工号共用lookup_contact协议；按名称/路径匹配获准部门，同名候选绑定原问题；完整分页计直属与含下级去重人数，已离职过滤。部门结果沿用私有双收件者卡片和无资料公开提醒，投递前检查绑定、配置、数据范围/应用权限及目标部门组织信息。失败不发布部分总数。进度显示已读部门/页和去重人数。

模型路由错误属于上游读取或只读决策故障，幂等登录读取及无副作用决策可恢复；不借用个人身份、不扩大通讯录范围，不将模拟恢复说成上游服务已修复。
