# 长任务、完整查询与大结果接续

程序1.52.0，更新2026-10-28。Node及依赖要求见package.json/package-lock.json。沿用自己的实例、分支、数据目录、机器人和环境配置；不要重启其它OS。更新前检查活动任务与未完成投递，备份并空闲停稳后部署。

## 已改变的执行规则

环境票据仍为15分钟，但正在执行的只读调查可以自动复核续期，不再因跨越该窗口而被迫拆轮重查。Runner在工具边界/收尾请求`environment-renew`；控制面验证当前任务、有效租约、原发起人/profile、项目、环境、模板、参数与配置指纹，再按当前只读策略生成同范围票据。原startedAt保持，续期审计和持久回执保存；重复请求不重复执行业务查询。排队导致未开始票据过期时，在领取前同样复核。取消、失效租约、配置/权限改变及错系统拒绝；不是永久授权，也不允许扩大目的或目标。单次已发出的网络读取仍受其请求超时约束，不能把工具边界检查说成对在途服务器操作的瞬时撤销。

完整SQL/Mongo取数、分页、关联、数据整理及文件核验不再设置统一的外层整批倒计时；每次数据库/SSH/HTTP请求仍保留超时。MySQL初始化的各条只读设置也使用明确请求超时。建议根据目标库与网络设置根`executionPolicy.mysqlQueryTimeoutMs`及`mongodbQueryTimeoutMs`；示例为600000毫秒，即单次10分钟，不是任务只能运行10分钟。固定连接检查及网站请求有自己的等待规则。旧exportTimeoutMs保留兼容，不再作为整批计算截止。没有新增整任务总时长、轮次或调用次数上限。

超时后保留原始错误、旧证据并重新建立只读连接。取消“同一轮相同查询曾超时就永不再执行”的禁止项，由规划器根据实际故障选择恢复、调整或明确再次读取；程序不自动盲重放模型会话、业务查询或写操作。

## 完整内容与历史数据

- 已保存数据集不再按24小时自动判无效。恢复仍核对当前授权、任务与来源范围、路径、完整性和SHA-256；原readAt/snapshot不变，超过24小时标记historical，不能冒充当前状态。用户需要最新数据时显式刷新并重算；原来的任务历史保留/活动依赖保护继续执行。
- 工具参数不再有8000字符的任意截停；必须是合法JSON对象，畸形输入只要求修正当前步骤。purpose不再按200字符截断，仍按模板类型、非空与控制字符规则检查并绑定原目的。其它固定模板的业务字段约束仍有效。
- 返回超过展示预算时，完整脱敏JSON存入本任务`exports/<JOB>/tool-results/`，文件0600、目录0700。返回resultRef、摘要、未展示字段及原始partial/complete；使用`list_tool_results`定位，`read_tool_result {resultRef,offset,limit}`续读，limit为1至4000字符，按nextOffset继续。展示预算不是业务截断；不得把某段文字当完整结果。跨进程和跨阶段可恢复，同项目其它任务、其它环境不能借用。原任务的保留策略覆盖这些文件；完整私有迁移必须连同datasets/CSV/核验记录成套保留。
- SQL的select字段、聚合项数、分组字段、IN项数/普通值长度、collect_values旧1000组及远程生成SQL旧100000字符等客户端任意上限已移除。仍只允许真实schema、固定操作及参数化查询；不是任意SQL。数据库本身的参数包、列数、资源与协议限制仍存在。大型关联优先使用完整数据集和setRef，避免将全量ID传入模型。
- 源码桥接不再因单文件256KB或排在前8份之后而丢文件。所有已核验允许文件都提供引用，前8份仅用于初始片段预算；其它按需读。长行使用startLine/textOffset与nextLine/nextTextOffset续读，不丢后半行。实际路径、普通文件、文件字节与摘要仍复核；配置、凭据、任意路径和越界链接仍不开放。
- 移除单次最多登记4份报表、显式共同交付最多20份的任意数量门槛。每份仍须通过原文件/核验记录/当前问题轮次和共同交付清单审阅；默认最后一份与显式多份交付语义保持。29MB分卷和平台上传、截图等实际传输边界继续保留，原生XLSX未因此获得支持。

## 工具发现与排错

SQL与Mongo环境工具以及网站规划器共享大结果目录/读取工具。规划器首次获得本任务历史大结果目录，环境结果保存toolResultCatalog供后续定位。不因大响应重查数据库，也不能仅看到连接成功或保存成功就标完整交付。已有inspect_dataset与inspect_report的分页、范围及独立数值核验继续执行。

续期失败应检查原租约、配置指纹或当前权限，不重新索取已有凭据。大结果无法读取应核对resultRef、当前任务/来源和摘要，不能放宽路径。恢复旧数据时核对历史取数与本次问题的时点要求；禁止静默刷新后冒充同一事务，也不将历史金额强行补零。

## 验证和回退

回归包括多窗口续期不重读、持久HTTP回执/并发重复/取消/撤权、旧票据排队领取、完整分页超过旧整批时限、跨环境拒绝、大参数与畸形输入恢复、完整结果重启续读/空值/脱敏/摘要篡改/符号链接、历史数据原时间、宽字段/多指标/完整集合、超过四份实际文件核验及大源码/长行完整读取。真实长请求时长、数据库负载和外部文件交付须另行验收，模拟时钟不等于真实长时间生产查询。

源码代码包包含新模块与说明，不包含私有配置/业务数据。完整跨机迁移时先安全停稳事件消费者，按现有加密迁移手册成套搬迁；未实测的目标OS不能声称通过。

回退须先空闲、备份并停止自己的实例，通过专用分支revert本次提交后测试部署。旧版会恢复24小时/参数/外层超时等规则，不能读取新的tool-results目录；保留这些证据，需接续大结果的任务等待兼容版本。若同时回退本机executionPolicy，仅逐项恢复原根请求策略，不覆盖任务历史或其它配置。未执行回退不称已验证。
