# 飞书机器人只读试点

由维护者在实例的 runtime 下配置 bot-read-pilot.local.json，并在安全窗口重启。仅实例内普通配置启用，默认关闭。模板参考 config/bot-read-pilot.example.json。需要目标助手已经可以读取已绑定的群历史，并启用该群的编辑消息补查。无需调整接收权限。租户、发送应用及接收助手标识从实际飞书消息与本机群/系统绑定核验。

只接一个群里单列的应用发出的独立文本问题，必须有飞书元数据证实明确 @ 目标助手。试点只识别测试环境、单个物料号和英文规格请求。原注册测试入口、账户约束与只读事务继续适用；只取配置里的测试表一个字段，核对完整性和唯一值。回复投递到原话题，内容不 @ 对方；回复、其它机器人及普通消息不能进入此通道，真人接待照常。

acceptAfter 指试点起始时间。确需处理既有一条请求时，可设置精确 seedMessageId，仍检查原消息身份和内容。磁盘按应用、群和消息标识保存查询凭证及投递回执；重复通知、重启或响应遗失沿用相同幂等键。回复验证方式是在原话题回读准确英文原文，核对本机回执，并确认其他发送应用、未 @、生产请求和回复串均被忽略。停用时移走配置后按实例流程安全重启，保留现有回执。
