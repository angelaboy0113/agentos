# 源码汇总读取同任务已保存数据

环境执行与源码汇总使用不同工具目录。环境返回“已保存149行”的摘要，并不意味着源码模型能看到149行；反复要求环境抄录也不能替代真实交接。

Runner在每轮只读源码执行前，按原job、原身份、实际源码环境对应的运行分级，重新核对既有环境证据、当前配置指纹、成员/管理员资格及关联项目授权。只为本job已有的datasets及已登记tool-results建立可读取索引，不发起业务查询、不扩大授权、不复制原始数据。

索引位于原任务exports目录的source-evidence-<sha256>.json，源码提示词提供其实际路径和摘要。普通数据集实际列、行、完整性字段在data中；分块数据集列在原清单，行按索引parts路径读取；工具结果需解开外层text JSON字符串。模型使用原只读文件工具读取完整值，按需筛选或分页，不需要一个不存在的“数据集读取”工具。

普通数据集的data原始JSON按流验证摘要，不把完整行数组复制到Runner内存。分块路径、数量、大小、摘要沿用已有存储验证。链接、损坏、错job/系统/环境、配置撤销均不能进入可用索引；缺项保留具体原因。来源取数时间、partial/complete与跨轮快照边界保持；数据可读不代表金额或业务结论已通过独立核验。

迁移沿用已有exports/datasets/tool-results目录，保留索引和原数据；没有新增私有配置或凭据。回退旧代码不删除这些已保存证据，不倒灌旧任务状态。其它操作系统和完整跨机迁移须单独验收。
