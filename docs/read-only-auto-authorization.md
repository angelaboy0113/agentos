# 只读排查自动授权

AgentOS 按操作能力决定是否需要人工审批。经过环境目录、查询模板、参数、项目和工具边界校验的只读操作自动执行，UAT 与 PRD 使用同一规则。源码阅读、配置发现、日志查看、数据库只读查询和业务网页查看可以在同一问题中连续推进，不再因为更换证据来源而重复要求用户批准。

自动授权只适用于程序内置的只读工具。数据库工具只生成参数绑定的 SELECT，在只读事务中运行，并限制库、基础表、字段、筛选条件、行数和超时；网页工具只开放经过检查的查看、查询、详情和翻页请求，并在网络层阻断保存、审批、启停、执行、删除、上传等变更请求；Nacos 工具只读取已登记命名空间和脱敏后的受控结果。模型不能提交任意 SQL、URL、脚本、凭据或本机命令。

以下操作仍需人工确认或管理员审批：

- 修改代码、数据、配置、权限或部署状态；
- 页面上的保存、提交、审批、启停、执行、删除、上传等写操作；
- 首次接入新环境、保存本机连接配置或凭据；
- 接受单目标非 TLS 连接等会改变安全配置的例外；
- 现有开发流程中会实际修改项目的实施阶段。

`planQuery` 为校验通过的只读计划写入 `approvedBy: policy:read-only` 和 `approvalRequired: false`。Runner 领取前及每次工具调用前仍检查环境配置指纹、项目、模板、参数、有效期和租约。自动授权不是永久放开环境，也不会让普通成员获得数据库账号、Cookie 或写权限。

启动时 `reconcileReadOnlyApprovals` 会重新校验旧版遗留的 `awaiting_environment_approval` 只读任务；校验通过的任务转为 `queued` 并继续，配置已删除、参数无效或范围不再匹配的任务保持暂停，不会降级为无边界访问。旧卡片无需继续点击批准。

验证覆盖 UAT/PRD 成员查询自动领取、源码到环境查询的自动接续、网页登录后自动恢复、查询参数修正后的自动重试、旧待审批任务迁移、过期范围重新签发，以及 SQL/网页写请求、跨环境、配置变化、错误租约和凭据泄露继续受阻。模拟回归不访问真实业务环境。
