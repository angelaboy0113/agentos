# 已交付文件接续

版本 1.75.0，2026-11-06。适用于程序已核验并成功投递的 CSV。无需新增配置、凭据或权限；升级程序后生效。原生 XLSX、多工作表、样式或公式编辑不属于本次新增能力，不能冒称支持。

在原话题 @ 原助手，例如“这份文件的金额是多少”“只保留编号和金额，金额列改名为原金额”“按编号筛选后再给一份”。接单目录 `deliveredFiles` 提供实际成功投递文件对应的 attachmentId；模型必须选择所需 ID，创建只读 analysis。新任务下载实际完整文件，续查与重启复用经过摘要校验的本机副本。文件不是长期知识、最新数据库或新的数据授权；更改金额口径、增加实时数据仍使用原有取证与独立核验。

目录取自同机器人、项目、群、可见问题链及成功文件回执。公开同话题成员可以追问；私有文件只供原私有身份继续。无关话题或另一个机器人不继承。环境标签保留，不能将 PRD 文件换成 SIT 证据。生成但未投递的草稿不在该目录；丢失或摘要损坏显示明确 unavailable，不要求用户重复上传已有可用文件。读取接口再次核对现有身份、问题链、回执、文件与核验摘要，不使用模型传入路径。

原环境已批准的 MySQL/Mongo 报表工具目录提供 `revise_report_file`：

```json
{
  "attachmentId": "从当前任务目录选择",
  "requirement": "保留两列并改表头，只保留指定编号",
  "columns": [{"from": "编号", "label": "编号"}, {"from": "金额", "label": "原金额"}],
  "filters": [{"column": "编号", "op": "eq", "value": "00001"}],
  "orderBy": [{"column": "编号", "direction": "asc"}]
}
```

columns、filters、orderBy 可分别省略；筛选为原字符串的 eq/ne，排序为稳定的字典序 asc/desc，不能猜测数字、时间或时区语义。工具不执行 SQL、不打开数据库连接、不执行任意代码；仍需当前有效的原环境工具授权。它保留原文件，生成独立 CSV 与 version=1 修订核验记录，保存源文件、原始取数窗口及固定转换配方。前导零、大整数金额、精确小数、重复、空单元格、引号及多行文字按原值保留；不自动补零或去重。需要新公式/金额时继续既有完整计算流程，本工具不提供改值接口。

生成后回源码审阅阶段，`inspect_report` 依据源文件和保存配方逐格重算实际新文件，包括连续修订的来源链；正常的业务交付审阅、最终卡片和 ReportDelivery 上传/重试保持。生成成功不等于已送达。重试只重发已核验文件并复用原幂等键，不重查数据库。不能仅改卡片颜色宣称完成。

迁移保留 agentos.json 的任务、文件回执、问题链以及整个 exports、datasets 和 attachments；任务对源 job 的引用受现有依赖清理保护。禁止只搬新 CSV 而丢来源/核验配方；缺失时停止修订并报告真实缺口。未改问答保留期限，无新依赖和整任务时间/次数上限。

验证包括合成真实 CSV 的生成、独立金额核验、接单建新任务、Runner 实际完整下载、本机 HTTP 附件接口、文件修改、全文件核验、模拟飞书发送失败/重试、再追问和来源保留；两个系统/PRD/SIT并行、私有范围、跨群/机器人/话题、损坏与符号链接拒绝。真实飞书用户入站至新版本文件送达、Windows 和整套跨机迁移另行验证，不用模拟回执冒充真人验收。
