可直接复用 → 快速回答同一版本，关键事实保持一致
有新事实 → 只补查差异复用方法，查询本次金额或状态

调查结束 → 提炼可共享的通用知识 → 核验证据与冲突 → 写入 SQLite，供下次复用
放在哪里？本机数据目录 / knowledge / knowledge.sqlite；个人对话和报表明细另存。
什么不能直接照搬？当前金额、单据状态、账号权限；历史案例不能当作新问题的结论。
怎样应对流程改造？接入实际部署版本清单；没有可靠信号时，只能提供近期历史参考。
已实现：索引检索 + 模型语义判断 + 程序校验。无需 Redis 或向量服务；命中不等于零模型调用。
