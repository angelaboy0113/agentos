# 网页展开控件与布局取证

用途：查询表单的“展开全部”“展开筛选（还有N项）”等本地展开状态、动态数量与装饰箭头可通过当前 `browser_snapshot` 引用操作。支持原生按钮、带交互语义的自定义元素和常见折叠面板；不会因为整块容器包含“展开”字样就开放点击。业务写动作、跨站、凭据、网络方法和路径审核仍独立生效。

入口：原网页调查环境目录提供 `browser_inspect({ref})`。使用最新引用检查当前控件和至多六层祖先的计算样式、尺寸、aria-expanded，以及所在表单输入控件总数和可见数。在点击前后分别检查；布局改变/文字改变都不是业务操作成功的充分证据。此工具仅作布局投影，不提供任意JS、CSS选择器、控制台缓冲、隐藏字段值、网络重放或应用内部状态读取。原始浏览器控制台中可能含凭据和业务报文，本能力不开放整段日志抓取。

没有新配置、权限、依赖或整任务截止。当前网页授权、原身份、项目/环境、页面目标和实时租约仍校验；失效、跨任务或已改变用途的引用拒绝操作。原生飞书表格走云文档工具，不提供布局工具。浏览器后端共用展开语义：隔离Playwright支持完整工具；macOS共享Chrome仅承诺其已实现的工具（本次增加布局投影），不代表其它浏览器工具均已实测。共享Chrome固定脚本已用真实浏览器DOM隔离回归；本机未安装日常Google Chrome，未验证真实Apple事件通道。

调查流程：先核对页面标题/路径，刷新快照；使用当前展开引用，对比布局/字段可见数；结合固定源码解释相互独立状态/样式覆盖。若需要返回网页继续，源码阶段应提交原 `websiteQuery`，不能因该阶段没有 `browser_*` 就将整个OS说成没有浏览器能力。未识别控件或真实权限受阻仍保留具体缺口，不能改绿冒充实测，也不反复点击未确认的操作。

本次真实生产复核与通用回归分别记录：实际页面结论不能泛化为所有页面已验收；修复AgentOS取证能力不修改业务系统的页面缺陷。迁移代码包包含本模块、说明和回归，私有迁移仍需保持已有网站环境/Keychain/会话边界。其他OS和整套跨机迁移未实测。
