# AgentOS 每日签到

机器人发一张长期使用的卡片，群管理员可在飞书置顶。成员点「今日签到」，按北京时间每天领取 1 分，私聊回执仅显示日期和当日已获得的积分，以及账号最新累计积分。重复签到显示同日已获得的积分。点「查我的积分」，机器人私聊发送账号累计的签到与有效提问积分。账号累计按可用历史记录跨群汇总，归档保留的提问也计入，助手机器人之间只通过可信真人身份映射合并。周榜继续按所选周期独立统计，个人累计不受周榜周期影响。红色「积分商城」按钮通过私聊回复“积分商城，敬请期待”，不变更积分。领取与查询使用程序规则，不启动 Codex 会话。

维护者通过受本机管理会话保护的 `POST /api/v1/admin/checkin-card` 发布。参数 `profile` 为指定系统助手，`group` 为已登记且该助手可服务的目标群。不传 group 时，只向这个助手配置的可信群主发私聊体验卡。申请体验无需给群加机器人或发群消息。接口返回卡片消息 ID，便于回读核验和置顶。同一群再次发布返回同一张卡。私聊可额外传入唯一的 `previewRequestId` 发送一张新的体验卡。同一编号重试会返回原卡，不重复发送。新旧体验卡共用体验积分。

飞书原生回调绑定原机器人、会话和消息 ID。群卡由实际点击人领取，体验卡只接受接收者。相同身份和北京时间日期只写一笔。已登记的可信真人身份关系会合并计分，排行榜的同名展示合并不用于个人计分或签到鉴权。正式签到与公开提问积分参与后台周榜和 Excel，管理员排除沿用原统计筛选。签到计一分而不增加提问互动数。体验积分单独持久化，周榜与正式积分查询排除。

个人累计使用后台的有效业务提问计分规则，加上已签到的天数。不同助手下的历史记录可通过两个助手分别读取同一条已登记群的原消息来核对作者身份。群通讯录姓名只用于找候选记录，最终以两边消息返回的账号和租户为准，核验结果在服务进程内复用。历史原消息无法核验时，回执标明累计的核验缺口。

上线核验需点击「今日签到」两次、查询一次，确认私聊收到相符的结果。跨日、个人隐私、群卡与体验记录隔离可用定向回归验证。群内正式验收须在获准群内进行。回退按原维护流程保留新旧状态文件，旧版会保留字段但不会处理新按钮或统计签到。

本机控制台的「签到统计」提供累计签到榜、当前连续签到榜和历史最长连续天数。按北京时间计日，同一人同一天只算一个签到日。今天还没签到时，连续天数可延续至昨天。点击榜单里的姓名可按日期查看此人的正式签到或按钮点击，点击明细只包含仍留存的正式回执及其私聊投递状态。体验卡记录独立。菜单使用现有本机管理员会话，无需新增飞书权限或配置。
