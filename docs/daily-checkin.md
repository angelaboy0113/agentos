# AgentOS 每日签到

机器人发一张长期使用的卡片，群管理员可在飞书置顶。成员点「今日签到」，按北京时间每天领取 1 分。点「查我的积分」，机器人私聊发送账号累计的签到与有效提问积分。账号累计按可用历史记录跨群汇总，归档保留的提问也计入，助手机器人之间只通过可信真人身份映射合并。周榜继续按所选周期独立统计，个人累计不受周榜周期影响。红色「积分商城」按钮通过私聊回复“积分商城，敬请期待”，不变更积分。领取与查询使用程序规则，不启动 Codex 会话。

维护者通过受本机管理会话保护的 `POST /api/v1/admin/checkin-card` 发布。参数 `profile` 为指定系统助手，`group` 为已登记且该助手可服务的目标群。不传 group 时，只向这个助手配置的可信群主发私聊体验卡。申请体验无需给群加机器人或发群消息。接口返回卡片消息 ID，便于回读核验和置顶。同一群再次发布返回同一张卡。私聊可额外传入唯一的 `previewRequestId` 发送一张新的体验卡。同一编号重试会返回原卡，不重复发送。新旧体验卡共用体验积分。

飞书原生回调绑定原机器人、会话和消息 ID。群卡由实际点击人领取，体验卡只接受接收者。相同身份和北京时间日期只写一笔。跨应用只用已有可信真人身份映射，用同名关联的排行榜显示不会作为个人查询或签到鉴权依据。正式签到与公开提问积分参与后台周榜和 Excel，管理员排除沿用原统计筛选。签到计一分而不增加提问互动数。体验积分单独持久化，周榜与正式积分查询排除。

上线核验需点击「今日签到」两次、查询一次，确认私聊收到相符的结果。跨日、个人隐私、群卡与体验记录隔离可用定向回归验证。群内正式验收须在获准群内进行。回退按原维护流程保留新旧状态文件，旧版会保留字段但不会处理新按钮或统计签到。
