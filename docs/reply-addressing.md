# 提问者称呼

可选功能，默认关闭。将 `config/reply-addressing.example.json` 复制为 ignored 的 `config/reply-addressing.local.json`，填写允许的机器人 profile、群 ID 和启用时点。也可用部署者环境变量 `AGENTOS_REPLY_ADDRESSING_FILE` 指定配置位置。启动新的程序版本需要按实例流程等待空闲、备份并重启；此后称呼配置按次读取。

机器人使用自己的身份读取当前群成员列表，只取 `member_id` 与 `name`，按当前 profile、群、当前提问者的 ID 找到显示名。需要该机器人已有 `im:chat.members:read` 或飞书接口接受的等价群读取权限；缺少时只申请必要权限，不申请整份通讯录，不借其他机器人或个人登录态。应用权限覆盖哪些群由飞书决定，程序还按配置的 profile/chatIds 收窄。

称呼只用于展示，不改变发送者、权限、任务所有者、原问题、正文证据、金额、附件、状态或完成判断。不读取性别或分析头像，不根据消息中的自称、历史另一人的姓名或模型输出认人。

## 配置与规则

- `enabled`：是否开启。
- `profiles`、`chatIds`：明确的允许范围；范围外不读取姓名也不添加称呼。
- `enabledSince`：ISO 时间，新消息创建时间达到它才生效；旧问题后续的新追问可以生效，不主动重写旧卡。
- `displayNameOverrides`：显示名精确匹配后的称呼例外，不是身份映射；同名者会使用同一称呼。只放在本机私有配置，公开例子不包含部署团队姓名。
- `fallback`：取不到姓名时的通用称呼，如“老师”；空字符串表示不加称呼，不猜名字。

默认使用“名字＋老师”。三个汉字的常见单姓姓名去掉首字，例如“王小明”称“小明老师”；常见复姓、两字姓名、四字姓名、英文或昵称保留完整显示名。不声称能准确拆分所有罕见姓名，特殊情况用例外配置。已有“老师”后缀不重复追加。

群成员姓名只在当前进程缓存15分钟，按机器人和群隔离，并发读同一群共用请求。查询失败短暂缓存60秒。辅助姓名查找最多等待2秒，失败或分页不完整退回 `fallback`，不会中断、限制或重跑业务任务。它不是整任务时间/轮次/工具次数上限。底层直接HTTP请求若仍在收尾，不会让业务答复继续等待姓名。

正式普通答复和任务结果卡的第一段添加一次称呼，已具有相同开头时不重复。进度卡、排队通知、完成提醒、文件内容、表格数值、按钮和问题标题不修改；已有投递重试沿用持久卡片，不为称呼重复执行业务查询。完整技术详情仍保留原正文。下一位用户在原话题追问时使用当前追问者的名字，不沿用首位用户的称呼。

## 验证与故障

运行 `node --test test/reply-addressing.test.js`，另跑实例要求的完整检查和代码包提取验证。用各机器人身份分别读取已授权群成员，确认当前成员姓名可用；一个机器人通过不代表其它机器人通过。合成卡片回归和实际姓名读取不等于真人新提问、结果卡投递的端到端验收。

取不到名字：检查当前 profile、群绑定、当前 senderId、启用时间和应用群读取权限。不要为称呼展开整个通讯录或扩大数据范围，不输出访问令牌。配置无效或缺失时功能关闭，业务链路继续。

迁移包含新增模块、测试、示例及本机 `reply-addressing.local.json`；姓名缓存不需要迁移。macOS 本机验证与其它OS代码路径应分别记录；未实际验证的 Windows/跨机步骤不能称已验收。回退可先关闭 `enabled`，不会修改历史业务结果或身份。若回退代码，按正常空闲备份和版本回退流程执行，保留新任务与回执，不回灌旧状态。
